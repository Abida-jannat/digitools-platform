My Project name is DigiTool.

DigiTools is designed to provide users with a simple and intuitive shopping experience for digital products. Users can explore various premium tools, add their favorite products to the cart, manage the cart, and proceed to checkout. The project is fully responsive and built with reusable React components.


 Technologies Used

- ⚛️ React.js
- ⚡ Vite
- 🎨 Tailwind CSS
- 🍞 React Toastify
- 📦 JavaScript (ES6+)
- 🌐 HTML5
- 🎯 CSS3

 Features:
 🛒 Smart Shopping Cart
- Add products to the cart.
- Prevent duplicate product additions.
- Remove products from the cart.
- Display total cart price.
- Cart count updates dynamically in the navbar.
- 
🔔 Toast Notifications
- Success notification when a product is added.
- Warning for duplicate products.
- Notification when a product is removed.
- Success message after checkout.
- Error notification for empty cart checkout.

  🎨 Modern Responsive UI
- Responsive product cards.
- Beautiful pricing section.
- Interactive "Get Started" steps.
- Call-to-action section.
- Professional footer with social media links.
- Mobile-friendly design.































# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

## Expanding the ESLint configuration

If you are developing a production application, we recommend using TypeScript with type-aware lint rules enabled.
